Install

curl -fsSL __SITE_URL__/setup.sh | sudo bash
sudo pacman -S __PRIMARY_PACKAGE__

The script verifies the signing key fingerprint below before trusting it.

bongocat-x-bin ships the Live2D renderer but not the Cubism Core library, which Live2D licenses prohibit redistributing. Install live2d-sdk-nonfree from the same repository to enable Live2D rendering: sudo pacman -S live2d-sdk-nonfree.

Or configure it by hand

Add this to /etc/pacman.conf:

 [__REPO_NAME__]
 SigLevel = Required DatabaseOptional
 Server = __SITE_URL__/$arch

Then import and locally sign the repository key:

curl -fsSLO __SITE_URL__/__REPO_NAME__-repo.asc
sudo pacman-key --add __REPO_NAME__-repo.asc
sudo pacman-key --lsign-key __KEY_ID__
sudo pacman -Syu
